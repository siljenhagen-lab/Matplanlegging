# Matplanlegging

En enkel app for å planlegge månedens middager og månedshandelen.

- **Plan:** kalender for måneden. Merk dagene dere er borte, og velg middag for dagene dere er hjemme.
- **Middager:** de vanlige middagene med ingrediensene de trenger.
- **Handleliste:** regnes ut fra middagsplanen, det du ønsker å ha på lager og det du pleier å bruke. Sjekk skapene, kryss av i butikken og registrer innkjøpet.
- **Lager:** hva som er hjemme. Trykk − når noe brukes og + når noe kjøpes.

Meieri, frukt og grønt fylles på ved behov, resten handles én gang i måneden.

Appen lagres på telefonen (ingen konto, ingen server) og kan legges til på hjemskjermen. Den virker også uten nett.

Åpne appen: https://siljenhagen-lab.github.io/Matplanlegging/
